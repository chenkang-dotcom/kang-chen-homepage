# Kang Chen · Personal Website

Academic homepage for **Kang Chen (陈慷)**.

## Local preview

Open `index.html` in a browser, or:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## GitHub Pages

This site is static. Enable Pages on the repository:

1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root (`/`)

Site URL will be:

`https://<your-github-username>.github.io/kang-chen-homepage/`

If you rename the repo to `<username>.github.io`, it will be available at:

`https://<username>.github.io/`
